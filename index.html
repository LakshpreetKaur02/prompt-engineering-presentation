01 — Introduction

What is Data Science?

An interdisciplinary field combining statistics, mathematics, computer science, machine learning, and domain expertise to collect, process, analyze, and interpret large volumes of data.

The goal: discover meaningful patterns, generate insight, and support better decisions — turning the flood of digital data into something organizations can actually act on.

KEY IDEA

Data Science transforms raw data into actionable knowledge.

05 — Raw Material

Types of Data

Structured

Rows and columns in relational databases — employee records, sales data, student information. Easy to search, analyze, and keep consistent.

Semi-Structured

Organized but not tabular — JSON, XML, and emails carry structure without rigid rows and columns.

Unstructured

No predefined format — images, video, audio, social posts, medical scans.

0 of the world's data is unstructured — one of Data Science's biggest challenges.

07 — Core Engine

Machine Learning in Data Science

Instead of explicit rules, computers learn patterns directly from data. Three branches, three ways of learning.

Supervised

Labeled data, known answers — price prediction, spam detection, diagnosis.

  • Regression
  • Classification
  • Linear Regression
  • Logistic Regression
  • Decision Tree
  • Random Forest
  • SVM

Unsupervised

Unlabeled data — segmentation, market basket analysis.

  • Clustering
  • Association
  • K-Means
  • Hierarchical Clustering
  • DBSCAN

Reinforcement

Agents learn via reward and penalty — robotics, autonomous vehicles, game AI.

  • Reward
  • Environment
  • Robotics
  • Autonomous Vehicles
  • Game-Playing AI
